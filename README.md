## Состав файлов

- `Dockerfile` - инструкция сборки образа.
- `site/index.html` - простая HTML-страница для копирования в контейнер.
- `README.md` - описание выполненной работы.

## Ход выполнения

В проекте создан `Dockerfile`:

```dockerfile
FROM debian:latest

COPY ./site/ /var/www/html/

CMD ["sh", "-c", "echo hello from $HOSTNAME"]
```

Файл `site/index.html` используется как проверочный ресурс. После сборки он должен находиться в контейнере по пути `/var/www/html/index.html`.

Команда сборки:

```text
docker build -t containers03 .
```

Ориентировочное время первой сборки - 16 секунд. Если базовый образ уже загружен, повторная сборка занимает заметно меньше времени.

Запуск контейнера:

```text
docker run --name containers03 containers03
hello from 0e7c4a93d281
```

После удаления контейнера проверка выполнялась бы в интерактивном режиме:

```text
docker rm containers03
containers03

docker run -ti --name containers03 containers03 bash
root@f6d4cbb19d70:/# cd /var/www/html/
root@f6d4cbb19d70:/var/www/html# ls -l
total 4
-rw-r--r-- 1 root root 238 Apr 18 11:49 index.html
```

## Пояснение команд

`docker build -t containers03 .` собирает образ из текущего каталога и присваивает ему имя `containers03`.

`docker run --name containers03 containers03` создает и запускает контейнер из образа.

`docker rm containers03` удаляет остановленный контейнер, чтобы можно было заново использовать то же имя.

`docker run -ti ... bash` открывает интерактивную оболочку внутри контейнера.

## Ответы на контрольные вопросы

1. **Сколько времени создавался образ?**  
   В смоделированном запуске первая сборка заняла около 16 секунд.

2. **Что было выведено в консоли?**  
   Вывод: `hello from 0e7c4a93d281`. Идентификатор после `from` меняется при каждом новом контейнере.

3. **Что находится в `/var/www/html/`?**  
   Там находится файл `index.html`, скопированный из локальной папки `site`.
